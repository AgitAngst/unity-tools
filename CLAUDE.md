# unity-tools — правила для сессий и агентов

Что это: репозиторий утилит владельца для Unity (редакторские скрипты и инструменты, которые
подключаются в разные проекты). Состояние и долги владельца — HANDOFF.md (заводится при первой
передаче); замысел и этапы — SPEC.md (по мере появления); документация того, что есть сейчас, —
[docs/README.md](docs/README.md); работа идёт через OpenSpec (`openspec/changes/<имя>`). Весь текст
пользователю — по-русски; тексты в интерфейсе инструментов — RU/EN.

## Скрипты

- Скрипты репозитория — в `scripts/`.

## Диски

- Только **E:** — репозиторий, worktrees, логи. Общая папка — `E:\dev_personal\unity-tools-scratch`
  (отчёты агентов — `reports\`). D: запрещён, R: мал для сборок.

## Проверка

- Быстрая сборка без Unity — `scripts\compile-check.ps1 -Source <Утилита>\Editor` (Roslyn из
  Unity 2019.4.41f2, его DLL, C# 7.3); после блока правок. Полная проверка — компиляция в самом Unity
  (тестовый сервер `scripts\audit-server.ps1` — один открытый редактор, журнал `unity-tools-scratch\reports\server\editor.log`)
  и автотесты `scripts\run-audit-tests.ps1`. Unity не перезапускать на каждый шаг: редактор открывается один раз и
  остаётся (владелец, 24.10.2026); тесты — в batch-редакторе, снимки — в видимом, проект открыт одним редактором за раз. План — [TESTPLAN.md](TESTPLAN.md), тесты — `tests/`. Результат — по ошибкам компиляции и коду выхода; вывод в файл, в разговор
  хвост.
- Основная цель — **Unity 2019.4** (C# 7.3): код должен компилироваться там, без новых возможностей
  языка (switch-выражения, `??=`, records, nullable-ссылки) и API новее 2019.4.
- Живая проверка в редакторе — за владельцем; не писать «проверено в редакторе» без его слов.

## Интерфейс

- Любое окно, диалог и правка вида — по [docs/ui-guideline.md](docs/ui-guideline.md) (скил `ui-guideline`);
  новое правило или решение владельца по виду — дописать туда в том же шаге (владелец, 15.10.2026).

## Работа агентов

- Исполнитель — свой worktree, коммиты по-английски в своей ветке, не пушит; называет ветку и хэш.
- Судья и сверщик документации — без worktree, читают `main`.
- Отчёт — до ~25 строк, подробности в `unity-tools-scratch\reports\<имя>.md`.
- Версию агент не меняет, если задача этого прямо не требует.

## Документация и коммиты

- Изменил поведение, меню, окно, формат файла — в том же шаге поправь `docs/`.
- Каждая утилита — своя папка и своя страница в `docs/`; `.meta`-файлы Unity коммитятся.
- Перед каждым коммитом — `scripts\stamp-version.ps1` (номер сборки в окне утилиты = число коммитов; новая
  X.Y.Z — `-Version`). Коммиты — по-английски. Пуш, выпуск и тег — по команде владельца.
