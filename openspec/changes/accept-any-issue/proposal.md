# Proposal

## Why

Владелец 27.10.2026: «Потом добавь возможность игнорировать любые замечания. Сейчас можно только те, где можно поставить галочку». Галочка была только у записей с исправлением или
объектом, поэтому настройки проекта и записи всей сцены без исправления нельзя было пометить допустимыми.

## What Changes

- Галочка у каждой записи, группы и строки копий; «Выбрать все» — все показанные записи.
- Пометка записи без объекта — для её сцены (`scene:<guid>`), если прогон проверял одну сохранённую сцену (одна открытая
  или сцены по одной); у нескольких открытых сцен вместе и у настроек проекта — для всего проекта (`*`, как раньше). Старые пометки `*` действуют во всех сценах; «Снять пометку» снимает и их.
- Этап плана: версия 2.5.0.

## Capabilities

### Modified Capabilities
- `scene-audit`: выбор и допустимые записи.

## Impact

- Код: `MultiSelect.cs` (без `CanPick`), `AuditorWindow.Problems.cs`, `AuditorWindow.cs`, `AcceptedList.cs` (ключ сцены,
  старые пометки, «SteamVR Plugin не найден» — для проекта), `AuditorWindow.Budgets.cs` (таблица сцен пересчитывается
  после «Снять все пометки» и «Включить»), `SceneAuditor.cs` (ключ сцены в прогоне одной сцены), `AuditIssue.cs` (`acceptScene`), `Strings.Ui.cs`
  (подсказки, пояснение на «Бюджетах»).
- Файл `ProjectSettings/SceneOptimizationAuditorAccepted.json`: новый вид ключа `scene:<guid>`; старые файлы читаются как
  раньше.
- Тесты: `AuditTestAcceptAny.cs`, шаг `accept-any` в `scripts/run-audit-tests.ps1`; `multi-select` в `AuditTests.cs` — без
  `CanPick`.
