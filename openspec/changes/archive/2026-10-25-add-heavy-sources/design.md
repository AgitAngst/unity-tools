# Design

## Context

Unity 2019.4: вложенные префабы и варианты, `PrefabUtility.GetCorrespondingObjectFromSource` (ближайший источник),
`GetOutermostPrefabInstanceRoot`, `GetPropertyModifications`, `ApplyPropertyOverride`, `IsPartOfImmutablePrefab`,
`SerializedProperty.prefabOverride`; `GetPrefabAssetPathOfNearestPrefabInstanceRoot` в 2019.4 нет. Собрано пробной
компиляцией 24.10.2026 (`unity-tools-scratch\probe\heavy`). Исправления сцены (`AutoFixer`) — Undo одной группой;
ассеты — одним пакетом `StartAssetEditing`. Источник для «Что здесь тяжёлое» уже есть в `ViewpointEstimator.Source`.

## Goals / Non-Goals

**Goals:**
- Одна строка и одно исправление на объект префаба вместо сотен записей и overrides.
- Видеть исходники уровня, которые дают больше всего треугольников, draw calls и памяти текстур.

**Non-Goals:**
- Правка моделей (FBX) из сцены — модели неизменяемы, их проблемы исправляются в импорте.
- Отдельная отмена префаба без копий: Ctrl+Z откатывает их вместе одной группой.
- Подсчёт памяти мешей и стоимости шейдеров в «Тяжёлых».

## Decisions

- **Источник записи** — `GetCorrespondingObjectFromSource(цель)`: объект в ближайшем ассете (префаб, вариант или
  модель). Строка копий — записи одной группы с одним источником; ключ — instance id источника.
- **Исправление в префабе — общее для всех исправлений сцены:** снимок `GetPropertyModifications` корня копии до и
  после исправления одной копии; новые и изменённые пути у источника применяются в его ассет
  (`ApplyPropertyOverride`, путь — `AssetDatabase.GetAssetPath(источник)`). Остальные копии: если хоть одно из этих
  свойств у неё своё (`prefabOverride`) — их исправление выполняется на них. Так не нужно переписывать каждую проверку.
- **Где выполняется:** отдельной корзиной `AutoFixer` — после исправлений сцены, вне `StartAssetEditing` (иначе копии
  не видят изменённый префаб до конца пакета), в своей группе Undo: `ApplyPropertyOverride` с `UserAction` пишется в
  Undo, Ctrl+Z откатывает префаб и копии (проверено тестом).
- **Строки и план кэшируются** по группе и состоянию списка (поиск, допустимые, прогон) — не на каждое событие окна.
- **Не предлагается:** запись без цели или с целью-ассетом (у них нет копий), модель, префаб вне `Assets/` и
  неизменяемый префаб, строка без части копий (поиск, неполный выбор, допустимые, удалённые) — префаб меняет все копии,
  а не выбранные. Если исправление не изменило ни одного свойства источника, каждая копия исправляется на себе.
- **«Тяжёлые»:** источник рендерера — тот же, что в «Что здесь тяжёлое» (`ViewpointEstimator.Source`: ближайший корень
  копии префаба → его исходный ассет, не вариант; иначе меш-ассет; иначе объект по имени). «Нет LOD» — у какой-то копии
  больше порога объекта и рендерер вне LODGroup. Копии — разные корни копий (у мешей — рендереры).
  Всё — только LOD0 (рендереры только из LOD1 и ниже — не копия и не в счёт), draw calls — число материалов, МБ — уникальные
  текстуры его материалов (`TextureMemory`), общие текстуры считаются у каждого исходника; доля текстур — от суммы по
  исходникам, чтобы доли складывались в 100 %.
- **JSON `heavy`** — считается при каждом прогоне аудита: 20 исходников по треугольникам; вкладка — та же функция.

## Risks / Trade-offs

- [Исправление меняет свойство, которое у копии раньше было своим] → это свойство применяется в префаб и перестаёт
  быть override у этой копии; у других копий своё значение остаётся и исправляется на них.
- [Вложенный префаб: правка идёт в ближайший ассет — внешний префаб] → внутренний префаб не трогается; это видно в
  окне подтверждения по пути префаба.
- [Числа «Тяжёлых» — оценка без теней, света и батчинга] → подпись на вкладке.
