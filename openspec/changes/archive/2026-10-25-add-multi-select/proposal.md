# Proposal

## Why

Владелец (23.10.2026): «добавь возможность выбирать несколько объектов, например при проставке галки Generate
Lightmap UVs; сделай для всего, что можно». Сейчас действие есть у одной строки или у всей группы сразу, а
выбрать, скажем, пять моделей из двадцати или выделить объекты в Unity, чтобы править их вместе в Inspector,
нельзя.

## What Changes

- **Проблемы:** галочка у каждого объекта (если есть исправление или объект/ассет) и у группы; «Выбрать все» в
  панели списка; полоса выбора: «Выбрано: N» (и сколько скрыто фильтром), «Снять выбор», «Исправить выбранные
  (M)», «Выделить в Unity (K)» — объекты и ассеты в Hierarchy и Project.
- **Развёртка под свет:** колонка галочек и галочка «все» в заголовке; полоса выбора: «Включить у выбранных (M)»,
  «Выделить в Project (N)» — файлы моделей для общего импорта, «Выделить объекты в сцене (K)» — все объекты с
  этими моделями (например, чтобы поставить Contribute GI), «Снять выбор».
- Исправления выбранного — через то же окно подтверждения.
- Тексты RU/EN, гайдлайн, документация, тесты. Это этап плана: версия 0.9.0.

## Capabilities

### Modified Capabilities

## Impact

- Документация: страница утилиты, гайдлайн (галочки, полоса выбора); тест `multi-select`, снимки.
