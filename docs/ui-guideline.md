# Гайдлайн интерфейса unity-tools

Правила вида редакторских окон утилит репозитория (Unity 2019.4, IMGUI). Сняты с первого окна —
`SceneOptimizationAuditor` (21.10.2026, `SceneOptimizationAuditor/Editor/AuditorWindow.cs`), переработаны
22.10.2026 по просьбе владельца «сделай понятнее и удобнее». Любое новое окно, диалог и правка вида — по
этому файлу; новое правило — дописать сюда в том же шаге (журнал внизу). Общие правила всех программ —
общий гайдлайн UX/UI владельца (скил `ui-guideline`); как они выглядят здесь — раздел 8.

Порядок, если источники расходятся: решение владельца → этот гайдлайн → общий гайдлайн → код. Расхождение
кода с гайдлайном — долг (раздел «Известные отклонения»).

## 1. Характер

Окна утилит — родные окна редактора Unity: стандартные стили `EditorStyles`, тулбар сверху, никаких
своих тем и шрифтов. Окно сначала отвечает на вопрос «что делать», потом даёт подробности:
вывод одной строкой → крупные счётчики → список сгруппированных проблем → объекты внутри группы.
Утилита ничего не меняет без явного действия пользователя; любое изменение — через окно
подтверждения со списком.

## 2. Окно

| Что | Значение | Где |
|---|---|---|
| Открытие | меню `Tools/<Имя утилиты>` | `[MenuItem]` |
| Наименьший размер главного окна | 560 × 460 | `AuditorWindow.Open` |
| Наименьший размер окна подтверждения | 520 × 340, `ShowUtility` | `FixConfirmWindow.Show` |
| Порядок сверху вниз | тулбар → вкладки → содержимое вкладки | `AuditorWindow.OnGUI` |
| Боковой отступ блоков | 8 px | `Padded()` |

- **Тулбар** (`EditorStyles.toolbar`): главное действие слева («Запустить аудит», после прогона — «Запустить
  снова», со значком Play), за ним пакетное действие и выпадающее «Сохранить отчёт ▾»; справа версия
  `vX.Y.Z.B` (`miniLabel`, подсказка «последнее число — номер сборки») и `EN | RU`. Версия — и на экране до
  первого прогона: владелец должен видеть, обновилась ли утилита (22.10.2026).
- **Вкладки** (`GUILayout.Toolbar`, высота 24): основная работа — первая вкладка; настройки и редкие
  инструменты — отдельными вкладками, а не свёрнутыми блоками под списком. У первой — число записей. Ширина вкладки —
  по подписи (`GUI.ToolbarButtonSize.FitToContents`), чтобы на ширине 560 подписи не обрезались (владелец, 24.10.2026).
- **Вкладка «Проблемы»:** вывод, карточки, строка контекста, полосы бюджетов, панель списка —
  неподвижны; прокручивается только список.
- **До первого прогона** — пустое состояние по центру: заголовок, 2–3 строки «что проверит и что не
  меняет», одна крупная кнопка (240 × 36), строка контекста мелко.
- Долгое действие (прогон, исправление, вход в Play Mode) запускается через `EditorApplication.delayCall`,
  а не прямо из `OnGUI`.

## 3. Цвета

- Свои цвета — только для смысла, константы `AuditorWindow`: `CriticalColor` (0.86, 0.27, 0.27),
  `WarningColor` (0.95, 0.72, 0.2), `InfoColor` (0.55, 0.55, 0.55), `OkColor` (0.3, 0.7, 0.35).
  Подложки — те же цвета с прозрачностью (`Tint`): вывод 0.14, карточка вкл. 0.2 / выкл. 0.05, строки
  списка — белый (тёмный скин) или чёрный (светлый) с 0.04 / 0.07 через одну.
- Текст цветом уровня (числа сверх порога, «нет», «есть») — свой оттенок на скин, контраст с фоном не ниже 4,5:1:
  тёмный скин — Critical `#FF8A8A`, Warning `#F2B833`, хорошо `#5CC968`; светлый — `#9E1C1C`, `#6B4700`, `#185A22`.
  Константы уровней — для полос, точек, подложек и значков (владелец, 24.10.2026).
- Выбранная строка таблицы (клик по строке) — подложка цвета выделения Unity поверх чередования строк.
- Уровень не передаётся одним цветом: рядом всегда встроенная иконка — `console.erroricon.sml`,
  `console.warnicon.sml`, `console.infoicon.sml`. Символы ⚠ ✕ не использовать.
- Ссылки (объект, ассет, настройка) — синий тон, свой для тёмного и светлого скина, курсор «рука».

## 4. Текст

| Роль | Стиль |
|---|---|
| Вывод | полужирный 13 |
| Число на карточке | полужирный 18 |
| Заголовок пустого состояния | полужирный 16 по центру |
| Название группы | `boldLabel`, затем ` · N` — число объектов (у общих проблем сцены числа нет) |
| Подсказка «Как исправить: …» | `helpBox`, 11, с переносом |
| Объект в группе | ссылка `label` с переносом; под ним текст записи `miniLabel` |
| Контекст (XR, stereo, качество, сцены) | `miniLabel` через « · » |
| Числа | EN — `2,000,000` и точка; RU — `2 000 000` (неразрывный пробел) и запятая (`FormatNumber`) |

## 5. Отступы и формы

- Колонка подписей в таблицах (бюджеты, метрики, полосы) — 210 px (`LabelColumn`), у полос не больше 35 %
  ширины.
- Карточки уровней — три в ряд, высота 46, зазор 4; включённая — с полосой 3 px цвета уровня снизу.
- Строка группы — высота 26, полоса цвета уровня 3 px слева; содержимое группы — с отступом 40 px.
- В группе — первые 100 объектов и кнопка «Показать ещё N» (`GroupPageSize`).

## 6. Элементы

- **Вывод** — одна строка на подложке цвета худшего уровня: «Критичных проблем: N — исправьте их в
  первую очередь» → «Критичных проблем нет. Предупреждений: N — стоит просмотреть» → «Нет ни критичных проблем,
  ни предупреждений».
- **Карточки уровней** — они же фильтры: клик скрывает или показывает уровень, число видно всегда,
  у скрытой — подпись «скрыто». Сведения (Info) по умолчанию скрыты; выбор хранится в `EditorPrefs`.
- **Список** — группы «одна проверка + один уровень», порядок: уровень, затем число объектов. У группы —
  простое название (`<checkId>.title`), подсказка с `checkId`, справа «Исправить» / «Исправить все (N)»,
  «Настройки» и (в режиме по важности) категория. Критичные группы развёрнуты после прогона.
- **Панель списка** (тулбар): поиск с крестиком, «По категориям», «Развернуть все», «Свернуть все».
  Пустой результат объясняет, сколько скрыто фильтром.
- **Кнопки действия** — только если действие возможно; недоступное пакетное — неактивным.
- **Подтверждение изменений** — своё окно (`FixConfirmWindow`), не `DisplayDialog`: список с галочками,
  группы «Сцена — откатывается Undo» и «Ассеты — меняются во всём проекте». Внизу справа: «Отмена»,
  затем «Применить (N)».
- **Выбор формата** — меню (`GenericMenu`) у кнопки, затем системный диалог сохранения.
- **Панель под кнопкой** (`PopupWindow`, кнопка с «▾») — когда перед действием надо выставить несколько галочек или
  значений: заголовок, поля, пояснение мелко, внизу справа «Отмена» и действие с числом в скобках. Меню
  (`GenericMenu`) — только для выбора одного пункта: галочку в нём не поставить, не закрыв его (владелец, 24.10.2026).
- **Тулбар вкладки на узком окне** не обрезается, а переносится во вторую строку: в первой — действия, во второй —
  «Сохранить CSV» и справа переключатели.
- **Простое сообщение** — `DisplayDialog` с одной кнопкой «ОК»; итог действия — `ShowNotification`.
- **Подсказки** (`tooltip`) — у кнопок тулбара (и переключателя языка), карточек, поиска, полос и названий групп.
- **Вкладка-таблица** («Развёртка под свет»): пояснение мелким текстом, тулбар (действие со значком Play, пакетное
  действие, «Сохранить CSV», справа фильтр), сводка полужирным, заголовок колонок `miniBoldLabel` с подсказками,
  строки 22 px через одну с подложкой, полоса слева у проблемных (красная — нет данных, жёлтая — есть, но плохие).
  Первая колонка — ссылка, остальные фиксированной ширины; значения «стоит / нет», «есть / нет» цветом
  (зелёный — хорошо, красный — плохо) и словом. Действие строки — справа, только если возможно.
- **Выбор нескольких** — галочки, а не Ctrl/Shift: у строки, у группы (все её строки) и в заголовке колонки
  таблицы (все показанные). Слот галочки одной ширины у всех строк (18–22 px); у строк, которые выбрать нельзя,
  слот пустой, чтобы подписи стояли на одной вертикали. Пока что-то выбрано — полоса выбора (`helpBox`) над
  списком: первая строка — «Выбрано: N» (и сколько скрыто фильтром) и справа «Снять выбор» (`miniButton`),
  вторая — действия над выбранным с числом в скобках; недоступное — неактивно; третья строка (если нужна) —
  решения команды: «Пометить допустимыми», «Снять пометку», «Отключить проверку». Новый прогон снимает выбор.
- **Допустимое** — не удаляется из списка, а скрывается по умолчанию и не считается; включается переключателем
  «Допустимые (N)» в панели списка; строки и группы — с меткой словом «допустимо» в начале текста. Отключение
  целой проверки — только с подтверждением, включение обратно — там же, где настройки (вкладка «Бюджеты»).
- **Вкладка настроек** («Бюджеты») — прокручивается целиком: обзор, пояснение в `helpBox`, таблица порогов с
  колонками «Предупреждение / Критично», внизу справа «По умолчанию» и «Сохранить» (по 130 px).
- **Вкладка истории** («История») — прокручивается целиком: выбор набора (`Popup`), строки-графики высотой 34 по
  колонке подписей (линия 2 px и точки 4 px цвета смысла: уровни — их цвета, бюджеты — зелёный или жёлтый по
  последнему значению; пунктир — порог Warning; серые линии — сравниваемые точки), справа значение и изменение
  «↑ +N / ↓ N» зелёным или красным; таблица точек (новые сверху, строки 22 px через одну с подложкой, слоты A и B
  по 22 px), блок заметки, затем сравнение «было → стало» той же колонкой подписей. Новых цветов нет.
- **Вкладка «Точки обзора»** (этап 1.2.0, ещё не в коде) — по доске https://claude.ai/artifact/5rYUsiTnTkFuqLNtSC6Bui:
  вторая вкладка; вкладка-таблица с тулбаром «Оценить» (значок Play), «Расставить точки ▾», «Добавить отсюда»,
  «Сохранить CSV», справа «Учитывать стены» и «Только сверх бюджета»; под таблицей у выбранной точки — «Направления»
  (8 строк, худшее полужирным с подложкой выделения) и «Что здесь тяжёлое» (сегменты «Треугольники | Draw calls»,
  метки словами); до первой расстановки — пустое состояние с кнопкой «Расставить точки…»; в Scene view — шарики
  цвета порога (серый — не оценена) с легендой словами, у выбранной — пирамида худшего направления, стрелка, ручка
  и подпись.
- **Вкладка инструмента** («Профайлер») — прокручивается целиком: главная кнопка 220 × 26 со значком, флажок
  `ToggleLeft`, у метрики — цветной квадрат 8 px, дельта «↑ +N / ↓ N» зелёная (лучше) или красная (хуже).

## 7. Языки и тексты

- Все тексты окна — RU и EN в одном классе `Strings` утилиты; язык выбирается переключателем и хранится
  в `EditorPrefs`; по умолчанию — язык системы.
- Тексты, зависящие от данных, хранятся ключом и аргументами и собираются при отрисовке — смена языка
  не требует повторного прогона.
- Консоль и журналы — только английский, с префиксом утилиты (`[SceneAudit] …`).
- Названия настроек Unity (Read/Write, Culling Mode, Spatial Blend) в RU-текстах — как в редакторе,
  по-английски. Названия групп — простыми словами, без кодов (`Текстура без mipmaps`).

## 8. Общие правила

Как разделы общего гайдлайна выглядят у утилит.

- **Окно и навигация:** окно редактора — тулбар → вкладки → содержимое; редкие инструменты — своими вкладками; версия —
  в тулбаре и на экране до первого прогона; до первого прогона — пустое состояние: что проверит и чего не меняет, одна
  крупная кнопка.
- **Списки и строки:** группы с простым названием и числом объектов; в группе первые 100 и «Показать ещё N»; поиск с
  крестиком в панели списка.
- **Кнопки:** действие — только если оно возможно, недоступное пакетное — неактивным; подсказки у кнопок тулбара.
- **Поверх окна:** подтверждение изменений — своё окно со списком и галочками: что откатывается Undo и что меняется во
  всём проекте, кнопки «Отмена» и «Применить (N)»; простое сообщение — `DisplayDialog` с «ОК».
- **Состояния:** вывод одной строкой по худшему уровню; уровень — цветом и встроенной иконкой; пустой результат
  объясняет, сколько скрыто фильтром; итог действия — `ShowNotification`; долгое действие — через
  `EditorApplication.delayCall`, а не прямо из `OnGUI`.
- **Тексты:** RU/EN в `Strings`, смена языка не требует повторного прогона; числа — по языку (`FormatNumber`);
  консоль — по-английски.
- **Не как в общем гайдлайне:**
  - палитры набора нет — стили `EditorStyles` и свои цвета уровней константами `AuditorWindow` (раздел 3);
  - главное действие — слева в тулбаре, как принято в редакторе Unity, а не справа;
  - темы — скин редактора; светлый снимками не проверяется (раздел 10);
  - движения нет: окна редактора на IMGUI не анимируются;
  - «▾» у «Сохранить отчёт» и «↑ / ↓» в дельтах «Профайлера» — текстовые символы, а не значки (раздел 10).

## 9. Как проверять

- Компиляция под 2019.4: `scripts\compile-check.ps1 -Source <Утилита>\Editor`.
- Снимки: `scripts\shoot-audit-window.ps1` — тестовый сервер (один открытый Unity 2019.4 с проверочным проектом), окно снимается через
  `PrintWindow` (`scripts\window-shot.ps1`), посторонние окна в кадр не попадают. Набор: пустое
  состояние, «Проблемы» RU/EN, «Развёртка под свет» RU/EN, выбор нескольких на обеих вкладках, «Бюджеты»,
  «Профайлер», «История» RU/EN — в тёмном скине; светлый скин код 2019.4
  переключить не может, его смотрит владелец вживую. Снимки —
  `unity-tools-scratch\reports\shots\`.
- Вживую (владелец): ширина 560 и широкое окно, длинные тексты переносятся, клики по карточкам,
  группам и объектам.

## 10. Известные отклонения

- Светлый скин не проверен снимками: код под 2019.4 скин не переключает, его смотрит владелец вживую.
- «▾» у «Сохранить отчёт» и «↑ +N / ↓ N» в «Профайлере» — текстовые символы вместо значков (общий гайдлайн: без
  шрифтовых символов); встроенных значков для них в редакторе нет.

- Вкладки окна пока равной ширины, текст уровней — цветами-константами одинаково в обоих скинах (красный на тёмном
  и жёлтый на светлом не держат 4,5:1): правила разделов 2 и 3 от 24.10.2026 входят в код этапом 1.2.0.
