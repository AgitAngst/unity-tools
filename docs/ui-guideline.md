# Гайдлайн интерфейса unity-tools

Правила вида редакторских окон утилит репозитория (Unity 2019.4, IMGUI). Сняты с первого окна —
`SceneOptimizationAuditor` (21.10.2026, `SceneOptimizationAuditor/Editor/AuditorWindow.cs`). Любое
новое окно, диалог и правка вида — по этому файлу; новое правило — дописать сюда в том же шаге (журнал
внизу).

Порядок, если источники расходятся: решение владельца → этот гайдлайн → код. Расхождение кода с
гайдлайном — долг (раздел «Известные отклонения»).

## 1. Характер

Окна утилит — родные окна редактора Unity: стандартные стили `EditorStyles`, тулбар сверху, плотный
список, никаких своих тем и шрифтов. Утилита ничего не меняет без явного действия пользователя;
любое изменение — через окно подтверждения со списком.

## 2. Окно

| Что | Значение | Где |
|---|---|---|
| Открытие | меню `Tools/<Имя утилиты>` | `[MenuItem]` |
| Наименьший размер главного окна | 540 × 420 | `AuditorWindow.Open` |
| Наименьший размер окна подтверждения | 520 × 340, `ShowUtility` | `FixConfirmWindow.Show` |
| Порядок сверху вниз | тулбар → шапка → обзор → фильтры → прокручиваемое содержимое → полоса итогов | `AuditorWindow.OnGUI` |

- Тулбар (`EditorStyles.toolbar`): главное действие слева, переключатель языка `EN | RU` справа.
- Полоса итогов внизу (`EditorStyles.helpBox`) не прокручивается: сводка слева, кнопки действий справа.
- Долгое действие (прогон, исправление, вход в Play Mode) запускается через `EditorApplication.delayCall`,
  а не прямо из `OnGUI`: так прогресс и диалоги не ломают раскладку.

## 3. Цвета

- Свои цвета — только для смысла, константы `AuditorWindow`: `CriticalColor` (0.86, 0.27, 0.27),
  `WarningColor` (0.95, 0.72, 0.2), `InfoColor` (0.55, 0.55, 0.55), `OkColor` (0.3, 0.7, 0.35).
  Остальное — цвета скина редактора.
- Уровень не передаётся одним цветом: рядом всегда встроенная иконка — `console.erroricon.sml`,
  `console.warnicon.sml`, `console.infoicon.sml`. Символы ⚠ ✕ не использовать: шрифт редактора 2019.4
  их не гарантирует.
- Ссылки (путь объекта, по которому можно кликнуть) — мелкий текст синего тона, свой для тёмного и
  светлого скина (`EditorGUIUtility.isProSkin`).
- Полоса бюджета: фон серый по скину, заливка зелёная / жёлтая / красная по порогам, тонкая метка порога
  предупреждения.

## 4. Текст

| Роль | Стиль |
|---|---|
| Заголовок блока, категория | `EditorStyles.boldLabel`, свёрнутый блок — `foldout` с полужирным |
| Текст проблемы | `label` с переносом |
| Путь, подсказка, служебные строки | `miniLabel` с переносом |
| Числа | `N0` / `N1`, инвариантная культура (`2,000,000`) |

## 5. Отступы и формы

- Колонка подписей в таблицах (бюджеты, метрики, полосы) — 210 px (`LabelColumn`).
- Счётчики в заголовке категории — три колонки по 52 px справа (`CountColumn`).
- Строка проблемы: отступ 16 px, иконка 18 × 18, слева полоска цвета уровня 3 px, между строками 4 px;
  кнопки строки — колонка 84 px справа.
- Длинный список — страницами по 200 строк и кнопка «Показать ещё N» (`PageSize`).

## 6. Элементы

- **Кнопки действия над строкой** («Исправить», «Настройки») — в колонке справа, только если действие
  возможно; недоступного действия кнопкой не показывать.
- **Подтверждение изменений** — своё окно (`FixConfirmWindow`), не `DisplayDialog`: список с галочками,
  группы «Сцена — откатывается Undo» и «Ассеты — меняются во всём проекте, Undo их не откатывает».
  Кнопки внизу справа: «Отмена», затем «Применить (N)».
- **Выбор формата** — меню (`GenericMenu`) у кнопки, затем системный диалог сохранения.
- **Простое сообщение** — `DisplayDialog` с одной кнопкой «ОК»; итог действия — `ShowNotification`.
- **Неактивное** — `EditorGUI.BeginDisabledGroup`, а не скрытие, если пользователю важно видеть кнопку.

## 7. Языки и тексты

- Все тексты окна — RU и EN в одном классе `Strings` утилиты; язык выбирается переключателем и хранится
  в `EditorPrefs`; по умолчанию — язык системы.
- Тексты, зависящие от данных, хранятся ключом и аргументами и собираются при отрисовке — смена языка
  не требует повторного прогона.
- Консоль и журналы — только английский, с префиксом утилиты (`[SceneAudit] …`).
- Названия настроек Unity (Read/Write, Culling Mode, Spatial Blend) в RU-текстах — как в редакторе,
  по-английски.

## 8. Как проверять

- Компиляция под 2019.4: `scripts\compile-check.ps1 -Source <Утилита>\Editor`.
- Вид — вживую в редакторе 2019.4 (владелец): оба скина (Personal и Pro) × оба языка, ширина 540 и
  широкое окно; длинные тексты переносятся, а не обрезаются.
