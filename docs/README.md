# unity-tools — документация

Версия программы: 0.1.0

Это документация того, что есть сейчас. Правила для сессий — [CLAUDE.md](../CLAUDE.md).

## Что это и что уже работает

Репозиторий утилит для Unity, которые владелец подключает в свои проекты. Пока в нём только
каркас: `.gitignore` для Unity, OpenSpec и правила для сессий. Утилит ещё нет — по мере появления
каждая получит свою страницу ниже.

## Оглавление

Страницы заводятся вместе с первой утилитой: как подключить в проект, как пользоваться, как
устроена.
